# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private vulnerability reporting: on the repository page, open the **Security** tab and choose **Report a vulnerability**. You will get an acknowledgement within 5 working days and a resolution or a status update within 30.

If the report concerns the hosted service rather than the code, say so; the fix path is different.

## Scope

- The code in this repository.
- The hosted service at gitgame.online, once it exists.

Out of scope: denial-of-service by playing the game badly, and social engineering of maintainers.

## Supported versions

Pre-1.0: only the latest release on `main` receives fixes.
