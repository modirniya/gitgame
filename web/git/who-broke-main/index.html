Who broke main

Something on main is wrong and you want the commit that did it, not the person. Git has three answers, each costing a little more: which commit last touched the line, which commit added the word, and which commit first made a test fail.

The line: git blame

%CAPTURE:blame%

Each line of the file with the commit that last changed it, its author and the date. The line that reads bug came from api: handle the edge case. Blame knows only the last touch: a reformat makes the formatter the author of every line, which -w (ignore whitespace) and --ignore-rev (ignore that commit) work around. git log -S bug goes further back: every commit that added or removed the word, wherever in the file it was.

The commit: git bisect

When you know main was good a while ago and is bad now, bisect does the search: it checks out the commit halfway between, you say good or bad, and it halves again. With a script that exits 0 for good and anything else for bad, git bisect run does the saying. Here the script is two lines, and the bug is a line in a file: 

#!/bin/sh
! grep -q bug api.py
%CAPTURE:bisect%

Four commits, two steps, and the first bad commit with its full record. git bisect reset returns to where you started. The usual script runs the test suite or the build; anything that can tell good from bad will do, and the search is the same for forty commits as for four, a few steps more.

The name

The command is called blame and the practice around it is called blameless, and both are right. The commit is the fact; the person is not the finding. A post-mortem that stops at a name learns nothing about why the line looked right to everyone who read it.

Why the game does this to you

In %BRAND% a bug is printed on a card, and only its holder sees it, so a commit on main may hide one until the release flips every commit face-up. blame is a card: play it on a face-down commit on main, and if it holds a bug its author takes -3 blame now, with the commit left face-up. bisect is in the tabletop deck, pointed at a range of main: its owner must say which half holds a bug. It isn't played online yet.
